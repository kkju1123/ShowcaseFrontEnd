# ShowcaseFrontEnd

个人作品展示网站，基于 React 19 + Vite 7 构建。

## 环境要求

- Node.js 20.19+ 或 22.12+（Vite 7 的要求）
- npm

## 启动方式

```bash
# 安装依赖
npm install

# 启动开发服务器（支持热更新）
npm run dev
```

启动后访问：<http://localhost:5173>

## 其他命令

```bash
# 构建生产版本，输出到 dist/
npm run build

# 本地预览构建结果
npm run preview   # 访问 http://localhost:4173

# 代码检查
npm run lint
```
